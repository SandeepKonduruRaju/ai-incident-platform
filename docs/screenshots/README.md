# Screenshots

Taken from tenant `demo` with the real LLM, by the read-only script `frontend/scripts/demo-screenshots.mjs`
(`npm run screenshots:demo` in `frontend/`) after seeding with `python -m app.seed_demo` in `investigation-worker/`.
The script writes `{list,investigation-confident,investigation-abstained,report-form}-{1440-light,1440-dark,390-light}.png`;
only the four `1440-light` ones are committed, to keep the repository small.
